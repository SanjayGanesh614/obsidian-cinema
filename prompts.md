### 2. Smooth Decoupled Parallax & Input Loop (DriftWall, OptionWheel & FlexCarousel)

Mark listeners as `{ passive: true }` where default scrolling is not prevented. Remove all synchronous layout reads (`getBoundingClientRect`, `document.elementFromPoint`) and React state updates (`setActiveId`) from inside raw `pointermove` handlers; cache container dimensions on resize/intersection, and update coordinates solely into lightweight mutable refs. Drive all plane tilt, inertia drift, and lens transforms strictly via frame-budgeted linear interpolation (`lerp` / exponential damping) inside the single `requestAnimationFrame` tick."
